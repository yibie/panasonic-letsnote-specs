# Panasonic Let's note AL-N3 Specifications

**English** · [日本語](../../ja/AL-N3/) · [中文](../../zh/AL-N3/)

**AL-N3** is a Panasonic Let's note laptop in the ace N3 series with a 12.1-inch SVGA display. This page lists all 3 part numbers, released 1997-07 – 1998-06.

## Part numbers

| Part number | Released | Discontinued | Summary |
| :-- | :-- | :-- | :-- |
| AL-N3T520J5A | 1998-06 | 1998-10 | MMX Pentium(200MHz)、HDD：3.2GB、CD-ROM、Windows 95 |
| AL-N3T520J5 | 1997-11 | 1998-03 | MMX Pentium(200MHz)、HDD：2.1GB、CD-ROM、Windows 95 |
| AL-N3T516J5 | 1997-07 | 1997-10 | MMX Pentium(166MHz)、HDD：1.6GB、CD-ROM、Windows 95 |

Panasonic no longer publishes a detailed spec sheet for this model; the summaries above come from the official discontinued-models list.
