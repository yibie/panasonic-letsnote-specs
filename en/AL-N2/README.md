# Panasonic Let's note AL-N2 Specifications

**English** · [日本語](../../ja/AL-N2/) · [中文](../../zh/AL-N2/)

**AL-N2** is a Panasonic Let's note laptop in the N2 series with a 10.4-inch SVGA display. This page lists all 3 part numbers, released 1997-06 – 1998-03.

## Part numbers

| Part number | Released | Discontinued | Summary |
| :-- | :-- | :-- | :-- |
| AL-N2T520J5 | 1998-03 | 1998-05 | MMX Pentium(200MHz)、HDD：2.1GB、Windows 95 |
| AL-N2T516J5 | 1997-10 | 1998-08 | MMX Pentium(166MHz)、HDD：2.1GB、Windows 95 |
| AL-N2T515J5 | 1997-06 | 1997-09 | MMX Pentium(150MHz)、HDD：1.6GB、Windows 95 |

Panasonic no longer publishes a detailed spec sheet for this model; the summaries above come from the official discontinued-models list.
