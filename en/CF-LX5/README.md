# Panasonic Let's note CF-LX5 Specifications

**English** · [日本語](../../ja/CF-LX5/) · [中文](../../zh/CF-LX5/)

🗄️ See this model in the [Let's note Cabinet](https://letsnote-specs.github.io/en/CF-LX5/).
