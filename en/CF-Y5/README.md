# Panasonic Let's note CF-Y5 Specifications

**English** · [日本語](../../ja/CF-Y5/) · [中文](../../zh/CF-Y5/)

🗄️ See this model in the [Let's note Cabinet](https://letsnote-specs.github.io/en/CF-Y5/).
