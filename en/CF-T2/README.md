# Panasonic Let's note CF-T2 Specifications

**English** · [日本語](../../ja/CF-T2/) · [中文](../../zh/CF-T2/)

🗄️ See this model in the [Let's note Cabinet](https://letsnote-specs.github.io/en/CF-T2/).
