# 松下 Let's note CF-T4 规格参数

[English](../../en/CF-T4/) · [日本語](../../ja/CF-T4/) · **中文**

**CF-T4** 是松下 Let's note 笔记本电脑，属于 T4 系列，配备 12.1英寸 XGA 屏幕。本页收录其全部 3 个型号（2005-05 – 2006-02 发售）的规格参数。每个型号均附官方规格表链接。
