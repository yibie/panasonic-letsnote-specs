# 松下 Let's note CF-M32 规格参数

[English](../../en/CF-M32/) · [日本語](../../ja/CF-M32/) · **中文**

**CF-M32** 是松下 Let's note 笔记本电脑，属于 mini M32/N4 系列，配备 8.4英寸 SVGA 屏幕。本页收录其全部 2 个型号（1998-06 – 1998-07 发售）的规格参数。每个型号均附官方规格表链接。
