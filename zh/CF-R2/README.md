# 松下 Let's note CF-R2 规格参数

[English](../../en/CF-R2/) · [日本語](../../ja/CF-R2/) · **中文**

**CF-R2** 是松下 Let's note 笔记本电脑，属于 R2 系列，配备 10.4英寸 XGA 屏幕。本页收录其全部 3 个型号（2003-05 – 2004-02 发售）的规格参数。每个型号均附官方规格表链接。
